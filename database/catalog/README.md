## Catalog Sources (Singapore Context)

This starter catalog is derived from Singapore-relevant references and international classification frameworks:

- BCA CDE Data Standard: https://www1.bca.gov.sg/buildsg/digitalisation/cde-data-standard
- BCA e-Catalogue / iNPQS references: https://www.corenet.gov.sg/ecatalog/pages/cataloguehome.aspx
- GS1 Singapore (construction product identification): https://gs1.org.sg/Industry/Construction.aspx
- ISO 6707-1 (buildings & civil engineering works vocabulary): https://www.singaporestandardseshop.sg/Product/SSPdtDetail/22953c30-1e89-4291-6e48-39fc34bd66e8
- Uniclass 2015 / OmniClass / MasterFormat (international classification patterns)

Notes:
- The CSVs are **brand-agnostic** and intended as a comprehensive baseline.
- Use the CSVs to seed `catalog_categories` and `catalog_items`.
- Extend or localize further based on project types (HDB, LTA, PUB, private sector).
