## 💡 Tips & Best Practices

### 1. Be Specific

**Good:**
- "What's the price of Portland cement?"
- "Generate quote for Office Building project"
- "Add 100 bags of cement to Warehouse project"

**Avoid:**
- "What's the price?" (too vague)
- "Quote" (not specific enough)
- "Add stuff" (unclear)

### 2. Use Project Context

**Good:**
- "Generate quote for Office Building" (uses project materials)
- "Add cement to Warehouse project" (adds to specific project)
- "Show quotes for this project" (uses current context)

**Avoid:**
- Creating quotes without projects (less organized)
- Not specifying project (AI doesn't know context)

### 3. Ask Follow-ups

**Good:**
- "What about steel bars?"
- "Can you add sand too?"
- "Show me the breakdown"

**This helps:**
- AI Agent understands context
- Builds on previous questions
- Provides better answers

### 4. Use Natural Language

**Good:**
- "I need to know the cost of materials for a foundation"
- "Create a project for warehouse construction"
- "Generate a quote with best prices"

**Avoid:**
- "cost foundation materials" (too short)
- "proj warehouse" (abbreviations)

## 🆘 Troubleshooting

### Issue: No supplier prices shown

**Possible reasons:**
- No suppliers have added that product
- Product name doesn't match

**Solution:**
- Try different product names
- Ask: "What products are available?"
- Contact suppliers to add products

### Issue: Quote seems wrong

**Solution:**
- Check quantities: "Show me the breakdown"
- Verify materials: "What materials are in this quote?"
- Regenerate: "Generate new quote for this project"

### Issue: Project not found

**Solution:**
- List projects: "Show me all projects"
- Check spelling: "Show me Office Building project"
- Create new: "Create project for [name]"

### Issue: Slow response

**Solution:**
- Check internet connection
- Wait a moment and try again
- Refresh the page
