Transform this construction pricing platform into an AI-first QS Assistant (ConstructGPT/QSGPT) where Quantity Surveyors can ask questions in natural language and get instant answers powered by real-time supplier pricing data.

CORE VISION: "ChatGPT for Quantity Surveyors - with real-time supplier pricing data"

REQUIREMENTS:

1. SIMPLIFIED USER SYSTEM (2 Types Only)
   - Remove ALL complex roles, approvals, and workflows
   - Keep only 2 user types:
     * Company Users (QS Professionals): type='qs', can use AI chat, cannot add/edit products
     * Supplier Users: type='supplier', can add/edit/delete products, cannot use AI chat
   - No approvals, instant access after registration

2. SIMPLIFIED DATABASE SCHEMA (3 Tables Only)
   Replace current schema with:
   - Organization: id, name, type (company|supplier), email, timestamps
   - User: id, organizationId, email, passwordHash, name, type (qs|supplier), timestamps
   - Product: id, supplierId, name, price, unit, timestamps
   Remove ALL other tables: DefaultPrice, PrivatePrice, PriceAuditLog, PriceView, QuoteRequest, QuoteResponse, ProductCategory, ServiceCategory, ProductImage, and all approval/status fields

3. SIMPLIFIED REGISTRATION
   Replace complex 7-option dropdown with:
   - Step 1: Radio buttons "I'm a QS Professional" or "I'm a Supplier"
   - Step 2: Radio buttons "Create new [company/supplier]" or "Join existing [company/supplier]"
   - Step 3: Email, Password, Name (optional)
   Remove: phone, address, postal code, approval workflows. Instant access after registration.

4. AI CHAT INTERFACE (Primary Feature)
   Create ChatGPT-like interface at /qs/chat for QS users:
   - Chat interface with message history
   - Input field for questions
   - AI responses with real supplier data embedded
   - Backend: POST /api/v1/chat endpoint
   - Integrate OpenAI/Claude API
   - Extract products from questions, query supplier database, generate AI response with real prices
   Example: QS asks "What's the price of cement?" → AI responds with actual supplier prices from database

5. SUPPLIER DASHBOARD (Secondary Feature)
   Simple product management at /supplier/products:
   - Add product form (name, price, unit only)
   - List products with edit/delete
   - No categories, SKUs, or images

6. AI INTEGRATION
   Create aiService.ts with OpenAI/Claude integration:
   - System prompt: "You are a helpful Quantity Surveyor assistant..."
   - Extract products/materials from questions
   - Query supplier database for real prices
   - Format supplier data in AI response
   - Generate helpful answers with actual pricing data

7. PERMISSION SYSTEM
   Simple type-based middleware:
   - requireQS() - checks user.type === 'qs'
   - requireSupplier() - checks user.type === 'supplier'
   - Protect routes: /api/v1/chat → requireQS, /api/v1/products (POST/PUT/DELETE) → requireSupplier

8. REMOVE/SIMPLIFY
   Remove: approval workflows, super admin, tenant admin, complex roles, private pricing, RFQ/Quote system, WebSocket, analytics, audit logging, categories, product images, service providers
   Simplify: registration (2 types), database (3 tables), permissions (type checks), UI (chat for QS, form for suppliers)

IMPLEMENTATION ORDER:
1. Update Prisma schema to 3 tables, create migration
2. Simplify auth service (remove approvals, 2 user types only)
3. Update registration endpoint and frontend (simple 2-step flow)
4. Add type-based permission middleware
5. Set up OpenAI/Claude API integration
6. Create AI service and chat endpoint
7. Create QS chat interface (ChatGPT-like)
8. Create supplier product dashboard
9. Update routing based on user type
10. Test end-to-end

SUCCESS CRITERIA:
- QS can register and use AI chat immediately (no approvals)
- Suppliers can register and add products immediately
- AI answers include real supplier prices from database
- QS can ask calculation questions and get totals
- Simple, focused, fast product

Key Principle: Simple First - 2 user types, 3 tables, instant access, AI-first approach with real supplier data.
