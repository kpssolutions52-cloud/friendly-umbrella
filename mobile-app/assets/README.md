# Place app icons here

For the app to build and run without asset warnings, add:

- `icon.png` — 1024×1024 app icon
- `splash-icon.png` — Splash screen image
- `adaptive-icon.png` — Android adaptive icon (foreground layer)

You can copy these from a fresh Expo template:  
`npx create-expo-app@latest _template --template blank` then copy `_template/assets/*` here.
