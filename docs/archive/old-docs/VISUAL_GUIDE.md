## 🔄 Data Flow Diagrams

### AI Question Processing Flow

```
┌─────────────────────────────────────────────────────────────────┐
│  QS Asks: "What's the price of cement?"                        │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 1: Check Cache                                           │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  Redis Cache: "ai:response:cement_price"                 │  │
│  │  Found? → Return cached answer                           │  │
│  │  Not found? → Continue to Step 2                         │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────────────────────────┬────────────────────────────────────┘
                             │ (Not in cache)
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 2: Extract Intent                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  Question: "What's the price of cement?"                 │  │
│  │  Intent: price_query                                     │  │
│  │  Entities: ["cement"]                                    │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 3: Query Database                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  SELECT * FROM products                                  │  │
│  │  WHERE name ILIKE '%cement%'                             │  │
│  │  ORDER BY price ASC                                      │  │
│  │  LIMIT 10                                                │  │
│  │                                                          │  │
│  │  Results:                                                │  │
│  │  - ABC Supplies: $50/bag                                │  │
│  │  - DEF Materials: $52/bag                                │  │
│  │  - GHI Builders: $48/bag                                │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 4: Build AI Context                                     │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  System Prompt:                                          │  │
│  │  "You are a QS assistant.                               │  │
│  │   Current supplier prices:                              │  │
│  │   - ABC Supplies: $50/bag                               │  │
│  │   - DEF Materials: $52/bag                               │  │
│  │   - GHI Builders: $48/bag                               │  │
│  │   Always include real prices in answers."               │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 5: Call OpenAI API                                       │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  POST https://api.openai.com/v1/chat/completions        │  │
│  │  Model: gpt-4-turbo-preview                             │  │
│  │  Messages: [system, user]                               │  │
│  │                                                          │  │
│  │  Response:                                               │  │
│  │  "Based on current supplier data:                       │  │
│  │   - ABC Supplies: $50/bag                               │  │
│  │   - DEF Materials: $52/bag                              │  │
│  │   - GHI Builders: $48/bag                               │  │
│  │   Best price: $48/bag"                                  │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 6: Cache Response                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  Redis: Set "ai:response:cement_price"                   │  │
│  │  TTL: 60 seconds                                         │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 7: Return to QS                                          │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  {                                                        │  │
│  │    "answer": "Based on current supplier data...",        │  │
│  │    "timestamp": "2024-01-15T10:30:00Z"                   │  │
│  │  }                                                        │  │
│  └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘

Total Time: < 2 seconds (with cache: < 100ms)
```
