# Supplier Guide - Complete Operations Manual

## 🎯 For Suppliers: Your AI-Powered Platform

**QS AI Agent** gives suppliers a complete AI-powered platform to manage inventory, prices, quotes, and orders - all through natural language and dynamic dashboards.

---

## 💡 What This Platform Does For You

### The Problem We Solve

**The Old Way:**
- QS calls you for quotes → You prepare manually → Send via email → Follow up → Repeat
- Update prices → Call/email all QS → Wait for responses → More follow-ups
- Manage orders → Track in spreadsheets → Manual updates → Phone calls

**The New Way:**
- QS asks AI Agent → AI queries your data → Instant quote → No phone calls
- Update prices via AI chat → All QS see instantly → No calls needed
- Manage everything via natural language → AI handles the rest

## 🚀 Getting Started (Suppliers)

### Step 1: Sign Up (30 seconds)

1. Go to registration
2. Select **"I'm a Supplier"**
3. Create or join supplier organization
4. Enter email, password, name
5. ✅ **Instant access - no approvals!**

### Step 2: Add Your Products (1 minute per product)

**Via AI Chat:**
```
You: "Add product: cement, $50 per bag"
AI Agent: "✅ Added cement at $50/bag. Available to all QS immediately!"
```

**Via UI Dashboard:**
- Go to Products page
- Click "Add Product"
- Enter: Name, Price, Unit
- Save

### Step 3: Start Using AI Chat

**Try these commands:**
```
"What products do I have?"
"Update cement price to $48"
"Show me quote requests"
```

## 💬 Complete Supplier AI Chat Commands

### Price Management

#### Update Base Price (All Companies)
```
"Update cement price to $48 per bag"
"Change steel price to $200 per unit"
"Set sand price to $2 per kg"
```

**AI Response:**
```
✅ Updated cement base price to $48/bag.
All companies will see this price immediately.
Previous price: $50/bag
```

#### Set Company-Specific Price
```
"Set cement price for Company A to $45 per bag"
"Give Company B special price: steel $195 per unit"
"Update sand price for Company XYZ to $1.80 per kg"
```

**AI Response:**
```
✅ Set special price for Company A:
Cement: $45/bag
Company A will see this price immediately.
Other companies see base price: $48/bag
```

#### Bulk Price Updates
```
"Update all prices: cement $48, steel $200, sand $2"
"Change prices: cement to $48, steel to $200"
```

**AI Response:**
```
✅ Updated prices:
- Cement: $48/bag

All changes are live now!
```

#### Remove Company-Specific Price
```
"Remove special price for Company A for cement"
"Remove Company B's special price for steel"
```

**AI Response:**
